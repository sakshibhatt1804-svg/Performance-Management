# PULSE: AI-assisted performance management for Groww

A working prototype for the Performance Hackathon: an evidence-led, explainable and contestable performance management system with Employee, Manager, HR/Admin and AI-governance views.

> **All employee data is synthetic.** The 160 employees and 16 managers are generated by `scripts/generate_data.py` (seed 2026). Nothing here is real Groww data, and the project is not affiliated with or endorsed by Groww.

## What it does

| View | Features |
| --- | --- |
| Employee | AI evidence band with factor-by-factor explanation, goals with SMART check, goal coach, evidence timeline, check-in logging, development plan, appeal (contest) with a 10-working-day SLA |
| Manager | Team table with AI bands and flags, explanation bars, live feedback-language coach, rating with mandatory evidence-based justification for overrides |
| HR & calibration | Manager leniency plot, hidden within-team group gaps, org-level adverse-impact ratios, case queue, calibration simulation, appeals queue, SHA-256 hash-chained audit trail with tamper test |
| AI governance | Kill switch, editable role-family weights, data whitelist, architecture diagram, model card, safeguards |
| Test lab | Runs the 25 automated tests in the browser |

The AI suggests; people decide. It never automates promotion, pay or termination.

## Run locally

No build step is needed: it's plain HTML, CSS and JavaScript.

```bash
# option 1: open index.html directly in a browser
# option 2: serve it
npm start            # http://localhost:3000
# or
python3 -m http.server 3000
```

## Run the tests

```bash
npm test             # Node 18+; prints 25 test results and writes docs/test_results.json
```

## Regenerate the synthetic data (optional)

```bash
pip install -r requirements.txt
npm run generate-data   # rewrites data/* and assets/data.js
npm test
```

## Deploy on Vercel

1. Push this folder to a new GitHub repository.
2. On vercel.com, click **Add New → Project** and import the repository.
3. Framework preset: **Other**. Leave build command and output directory empty (root `/`).
4. Click **Deploy**. The site is served from `index.html`.

Or use the CLI from this folder: `npx vercel` (then `npx vercel --prod`).

## Project structure

```
index.html              App shell
assets/
  styles.css            Styles (light and dark)
  engine.js             Scoring, explanations, language and goal coaches, fairness audit, audit log, appeals
  tests.js              25 automated tests (shared by Node and the in-browser Test lab)
  data.js               Synthetic dataset as window.RAW_DATA
  app.js                UI for all five views
data/                   Synthetic dataset: JSON, CSV and Excel workbook with answer key
scripts/
  generate_data.py      Seeded synthetic data generator with injected bias scenarios
  run_tests.js          Node test runner
docs/                   Deck (PPTX, PDF), test results (v1 and final), iteration log
```

## Results

The final version passes 25/25 tests. The first version passed 22/25; see `docs/iteration_log.md` for how significance testing, continuous residuals and alert/watch tiers fixed the false alarms on small teams. The calibration impact figures are a simulation on synthetic data, not a forecast.
