# PULSE: AI-assisted performance management for Groww

Hackathon submission: an evidence-led, explainable and contestable performance management system, with a working prototype, synthetic test data and test results.

> **All employee data is synthetic.** The 160 employees and 16 managers are generated by a seeded script. Groww facts come only from cited public sources. This project is not affiliated with or endorsed by Groww.

## Pages

| Page | What it is |
| --- | --- |
| `index.html` | Overview: the 8-part story from the brief (challenge, diagnosis, principles, process, AI architecture, prototype, tests, roadmap) plus all deliverable downloads |
| `app.html` | Live prototype: Employee, Manager, HR & calibration, AI governance and Test lab views |
| `evidence.html` | Test results (25/25), iteration log, limitations, evidence log and sources |

The AI suggests; people decide. It never automates promotion, pay or termination.

## Deploy on Vercel (no build step)

1. Create a new GitHub repository and upload **the contents of this folder** (so `index.html` sits at the top level of the repo). Include the hidden files `vercel.json` and `.vercelignore`.
2. On vercel.com, choose **Add New → Project** and import the repository.
3. Set **Framework Preset** to **Other**. Leave Build Command, Install Command and Output Directory empty. `vercel.json` already declares a static site.
4. Click **Deploy**.

If you ever see "No python entrypoint found", the project is set to the Python preset. Open Settings → Build & Deployment, choose **Other**, save, and redeploy.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .          # or: python3 -m http.server 3000
```

## Tests and data (optional, for reviewers)

```bash
npm test                                   # Node 18+: runs the 25 tests, writes docs/test_results.json
pip install -r tools/requirements.txt      # only needed to regenerate data
python3 tools/generate_data.py             # rewrites data/* and assets/data.js (seed 2026)
python3 tools/build_evidence.py            # rebuilds evidence.html from docs/test_results.json
```

## Structure

```
index.html  app.html  evidence.html
assets/   site.css, site.js (overview and evidence pages)
          styles.css, app.js (prototype UI)
          engine.js (scoring, explanations, coaches, fairness audit, audit log, appeals)
          tests.js (25 tests, shared by Node and the in-browser Test lab)
          data.js (synthetic dataset)
data/     synthetic dataset: Excel with answer key, CSV, JSON
docs/     deck (PDF, PPTX), evidence PDF, test results (v1 and final), iteration log
tools/    generator, test runner, evidence-page builder (not deployed)
```
